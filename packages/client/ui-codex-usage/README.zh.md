# `@deepseek-ai/dsh-client-ui-codex-usage`

[English](README.md) | 中文

浏览器端插件在界面右上角显示 ChatGPT/Codex 计划的会话和每周使用窗口。主机端使用已配置的 `CODEX_ACCESS_TOKEN` 请求用量；Bearer token 不会通过 RPC 发送到浏览器。

## 配置

无需配置。未连接 Codex 或用量接口不可用时，组件会显示错误信息，不会阻止会话使用。

## 模型体验

无。本包只向用户呈现服务商报告的账户用量，不注册任何面向模型的功能。

#### KV 缓存影响

无；本包不组装服务商请求。

## 已知限制与后续工作

- ChatGPT 用量接口由服务商维护，字段和可用性可能变化。
- 组件在挂载时和每 30 秒刷新一次；该指标仅供参考，不会限制请求。
